# Phase Planner

1. Lee todos los documentos de docs/requirements/.
2. Extrae requisitos funcionales, no funcionales y restricciones.
3. Propón un roadmap de 3-7 fases.
4. Para cada fase define: objetivo, entregables, criterios de aceptación, dependencias, complejidad (S/M/L) y riesgos.
5. Genera Artifact en docs/phases/roadmap.md.
6. No implementes código.
